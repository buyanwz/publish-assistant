免费多平台发布助手

不订阅、不把账号交给第三方、不上传你的视频。
日常发布只做两件事：上面填一次，下面复制一次，然后去各平台粘贴、自己点发布。

第 1 步：一次填好

保存说明：标题、描述、话题和发布进度会自动存在这个浏览器里，下次打开还在。视频和封面文件本身不保存，每次重新选一下就行。

极简发布：填一次，复制一次

下面这段就是通用版，绝大多数平台直接粘贴就能用，不用每个平台单独复制。标题太长、标签太多的平台，下面详细版里会单独提醒你。

然后：打开平台 → 粘贴 → 上传视频 → 你自己点发布 → 回来把那个平台改成“已发布”。就这样，没别的步骤。

详细版（不用每次都看）

顺序就是：小红书 → 抖音 → B站 → 视频号 → YouTube → 快手 → 百家号 → 拼多多。哪个平台不想发，把它前面的勾去掉就行。

核对：只做一次，不是每次发布都做

这就是你说的能力，也是现在最需要你的地方：你点开一个平台的上传页，对照下面那张核对表，看到什么就勾什么。不用一次核 8 个，先核 1 个，点“导出核对结果”发回给我，我就按你看到的真实页面去改 Skill，改完你再核下一个。

核对表在每个平台卡片下面，点“展开核对表”就能看到。每一项只有三个选项：对得上 / 找不到 / 不一样，不一样就写一句你看到的是什么，比如“最终按钮叫发表，不是发布”。

先从最简单的开始：小红书。你点开它的上传页，看看标题框、描述框、话题、封面、原创勾选、最后那个按钮，分别是什么样子，勾完导出发我就行，其他平台先不用管。
