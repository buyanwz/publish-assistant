# 免费多平台发布助手

一次填好标题、简介和标签，8 个平台复制粘贴发布，不订阅、不用安装。

支持：小红书、抖音、哔哩哔哩、微信视频号、YouTube、快手、百家号、拼多多。

## 用法

1. 下载 `index.html`，双击用浏览器打开就能用（也可以直接在这个仓库点开它）。
2. 填一次标题、简介、标签，每个平台可以单独改一版。
3. 点复制，到对应平台的上传页粘贴、发布。
4. 进度保存在浏览器本地，下次打开还在。

## 更新

以后有新版都会推到这个仓库：

- 用 git 的：`git pull` 一次就拿到最新版。
- 不用 git 的：重新下载最新的 `index.html` 覆盖旧文件即可。

注意：已经下载到电脑上的旧文件不会自己变，一定要从这里拉取或重新下载才会更新。
